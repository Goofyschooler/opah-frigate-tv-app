# Opah 0.4.0

Opah 0.4.0 redesigns the app around the way people use cameras from a sofa:
open a favorite view, see what happened, and keep the moments that matter.

## A simpler Home

- Preview the focused camera in a large, clear picture before opening it.
- Pin favorites, reorder them, or hide cameras you do not need on Home.
- Open saved views and Frigate camera groups, or start All Cameras directly
  from Home.
- Choose whether Opah starts on Home, the last view, a camera, or a saved view.

## Better live viewing

- Choose **Go back 30 seconds** and return to live video automatically.
- Choose **Take snapshot** to capture the current camera picture and share it
  from the TV.
- On supported Frigate 0.18 servers, administrators can start or stop an
  on-demand recording.
- See the current Frigate 0.18 Mode. Administrators can switch Modes after a
  confirmation and quickly undo the change.

## Review activity as a queue

- Move through new activity without returning to the grid after every item.
- Choose **Next activity** while a saved Activity video is playing to continue
  through the same list without leaving the player. The control becomes
  unavailable when no later playable item remains.
- Return from playback to the same Activity item, filters, and list position.
- Optionally mark an item reviewed after its video finishes.
- Mark every new alert currently shown as reviewed after one clear warning.
- See a clear caught-up state when the queue is complete.
- Find similar activity or keep a clip from the same details screen.
- Reuse recent searches, start with simple suggestions, or use television voice
  input when it is available.

## Move through History

- Navigate saved video on a continuous timeline.
- See recording gaps, motion, detections, and alerts in the same time context.
- Hold left or right to move faster and choose a 5-minute, 30-minute, or 2-hour
  view.
- Reveal other cameras at the same time without leaving the timeline.
- On supported Frigate 0.18 servers, choose part of the picture and use
  **Find motion here**.

## Clips and Incidents

- Browse kept video in the redesigned **Clips** page.
- Share a clip from the TV. Frigate administrators can also rename or delete a
  clip after confirmation.
- Use **Save all angles** to keep the same moment from several authorized
  cameras on supported Frigate 0.18 servers.
- Frigate administrators can create simple **Incidents** and move clips into or
  out of them.

## Make Opah yours

- Start with a built-in color style or use the remote to make your own.
- Adjust the accent and background while seeing each change right away.
- Keep focus easy to see with optional high contrast and reduce interface
  movement when preferred.

## Easier updates

- Let Opah check quietly for a new release after it starts, or turn automatic
  checks off.
- Read longer release notes with the remote before choosing whether to download
  an update.

## Compatibility

Opah 0.4.0 supports Frigate 0.17.2. Features that need Frigate 0.18 were built
for the exact Frigate 0.18.0 beta 3 build `344efb6` and stay hidden on Frigate
0.17.2. Live testing with that beta was limited, so those newer features may
still need refinement.

Camera movement, zoom, focus, and saved positions remain unverified with a
physical PTZ camera. Support may vary by camera.

## Update Opah

Open **Settings** > **Update** in Opah, or download the APK from the
[Opah releases page](https://github.com/VibeCodingAntagonist/opah-frigate-tv-app/releases)
and open it on the TV. Android should update Opah without removing the saved
connection or local choices.

Only download Opah from this GitHub repository. Do not install copies from
unofficial APK websites or mirrors.
