# Opah 0.5.1

Opah 0.5.1 is a small update that restores a missing Activity action and adds
support for a common local Frigate connection.

## Activity

- **Mark all reviewed** is visible on the New Activity page again.
- The action marks the new items currently shown, including the selected
  activity type and filters, after you confirm the change.

## Local Frigate connections

- You can connect directly to Frigate port `5000` without entering a username
  or password.
- Opah identifies this as a no-account, full-access connection and does not
  send or save account credentials for it.

Port `5000` should only be used on a trusted private network because it provides
full access to Frigate. Most people should continue using Frigate's normal
authenticated address and account.
