# Opah 0.5.0

Status: draft release notes

Opah 0.5.0 helps a household stay aware without keeping cameras on screen all
day. It adds optional TV alerts, a calm Monitor Mode, a short Home briefing, and
shared-TV privacy controls.

## A clearer television interface

- A rebuilt Android TV interface uses compact navigation, consistent focus
  outlines, and less empty space.
- Activity separates new and reviewed items and provides visual controls for
  search and motion search.
- Appearance, Server Performance, and Server Storage use visual controls and
  dashboards instead of long text-only lists.
- First-time connection keeps the normal Frigate address simple and reveals a
  separate live-video address only when it is needed.

## TV alerts you control

- Get native Android TV notifications for important Frigate activity while
  another TV app is open.
- Start with important activity or choose custom cameras, activity types,
  recognized labels, schedules, Frigate Modes, and threat levels.
- Snooze all Opah alerts for 15 minutes, one hour, until tomorrow, or until the
  active Frigate Mode changes, without changing reviewed activity.
- Choose a full preview, blurred preview, or text only.
- Send a local test alert and see when Android permission or channel settings
  are blocking delivery.

## Privacy for a shared television

- Set a local PIN for private areas and actions.
- Choose which app areas, administrative actions, destructive actions, and
  private cameras require that PIN.
- Lock the selected areas again at any time without signing out or changing
  the Frigate account.

For the strongest protection, use a dedicated restricted Frigate account for
the TV. Opah's local controls do not replace Frigate permissions.

## Monitor Mode

Start Monitor Mode from a saved View or Frigate camera group. Opah keeps the
quiet view lightweight and can bring one active camera forward when important
activity occurs.

Choose Fixed, Calm, Active, or Patrol behavior. Audio starts off, and you can
set an exit timer or keep the screen awake. Opah returns to the normal View
after activity settles.

## Since you last watched

Home now shows a compact factual briefing only when there is unseen activity.
It works without generated summaries. When Frigate provides analysis, Opah
labels it separately.

- **Play highlights** opens a bounded sequence and remembers only completed or
  explicitly skipped items.
- **Review new** opens the same items as an Activity queue with normal Frigate
  reviewed controls.
- **Dismiss** acknowledges only the authorized items currently shown and does
  not mark them reviewed in Frigate.

## Playback reliability

Opah can test valid stream, transport, audio, and decoder choices, fall back
when a choice fails, and remember the working result for that camera and TV.
**Cameras and Playback** settings include **Check camera compatibility**, a
clear explanation of the automated check, technical choices for advanced
users, and a reset for remembered choices.

## Compatibility and limitations

- Frigate 0.18 is the primary API generation. Opah also keeps legacy support
  for Frigate 0.17.2, with newer-only controls hidden where unavailable.
- TV alerts depend on Android notification and background restrictions. Some
  televisions may delay background or reboot delivery.
- Monitor Mode and H.265 playback depend on the TV's video hardware.
- Two-way talk is not included.
- PTZ behavior still needs testing with a physical PTZ camera.
