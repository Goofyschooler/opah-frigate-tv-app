# Opah 0.3.0

Opah 0.3.0 adds camera groups, saved recordings, camera controls, activity
search, and a simple way to get future updates.

## Watch cameras together

- Choose two to four cameras and watch them together.
- Save a favorite group on the device and give it a name.
- Open camera groups already set up in Frigate.
- Use picture-in-picture with two cameras on compatible TVs.

Camera groups are muted and use lower-bandwidth video when it is available. The
number of cameras a TV can play at once depends on its video hardware.

## Find saved activity

- Browse saved video by camera, day, and hour.
- See where more motion happened in saved video.
- See how much activity still needs review and review everything currently
  shown at once.
- See clearer details, including Frigate summaries, recognized names, and
  license plates when available.
- Find activity that looks similar to an item you are reviewing.
- Filter activity by camera, object, recognized name, area, license plate,
  time, or review status.
- Mark activity as reviewed or not reviewed from its details or while watching
  its video.
- Search using a short description when this feature is set up in Frigate
  0.17.2 or 0.18.
- Save a selected part of History as a recording.

## Save recordings

- Save a recording from activity details or while watching its video.
- See a preview picture and details for every saved recording.
- Play saved recordings from the new Saved page.
- Frigate administrators can permanently delete a saved recording after a
  confirmation warning.

Saved recordings stay in Frigate. Opah does not upload them to another service.

## Control compatible cameras

Opah can show controls for movement, zoom, focus, and saved positions when the
camera and Frigate support them. Cameras without these features will not show
the controls.

Camera controls are new in this release and have not yet been tested with a
physical PTZ camera. Support may vary by camera.

## Fill the television screen

Choose whether each camera fits inside the screen or fills the whole screen.
Opah remembers the choice for each camera on the device.

## Get Opah updates

- See an indicator when a newer Opah release is available.
- Read the release notes on the Update page.
- Download the official APK and open it with Android's installer.
- Download the newest Opah APK using the stable `opah-latest.apk` filename.

Nothing downloads or installs automatically. Android may ask for permission
the first time Opah opens a downloaded update.

## Update Opah

Open the [Opah releases page](https://github.com/VibeCodingAntagonist/opah-frigate-tv-app/releases),
download `opah-latest.apk` from the newest release, and open it on the TV.
Android should offer to update Opah while keeping the saved connection and
local choices.

You can also install the update from Opah's Update page.

For a new installation, or if you need more help, follow the
[step-by-step installation guide](../installation.md).

Only download Opah from this GitHub repository. Do not install copies from
unofficial APK websites or mirrors.

See the [Opah interface gallery](../screenshots.md) for fictional examples of
these features on a television.
